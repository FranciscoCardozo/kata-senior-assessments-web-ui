# KataSeniorAssessmentsWebUi

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.2.27.

## Levantar aplicación en local

Para levantar la aplicación en local utilizar el siguiente comando: 

```bash
ng serve
```

Una vez en local se podra ingresar a las diferentes rutas que se tengan configuradas en el proyecto.

## Comandos comunes

Comandos mas utilizados de angular cli, para la creación de componentes y servicios.

1. crear componente

```bash
ng g c component-folder/component-name
```

2. Crear servicio

```bash
ng g s services/folder-service/service-name
```

3. Para mas documentación de otros comandos en angular ejecutar: 

```bash
ng generate --help
```
